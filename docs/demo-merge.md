# 영재 데모 통합

`영재 데모/src`의 실제 구현을 기존 플래너와 비교했습니다. 데모의 자료함·주간 시간표·색상 표현을 가져오고, 현재 앱의 학기·방학·할일·개인 핀·버스정류장·공유 XML 기능은 유지했습니다. 원본 데모 폴더와 그 안의 사용자 데이터는 수정하지 않습니다.

## 차이와 반영 방식

| 항목 | 영재 데모 | 통합한 앱 |
|---|---|---|
| 건물 더블클릭 | 건물별 미니 자료함 | 선택 시즌의 과목 폴더와 일반 자료 목록을 표시 |
| 지도 일정 번호 | 장소별 일정 순서 표시 | **번호를 누르면 해당 일정의 과목 자료함을 직접 열기**, 같은 건물에 여러 일정이 있으면 번호·이름 선택 |
| 비수업 일정 번호 | 별도 과목 연결 없음 | 해당 장소·시즌의 일반 자료 폴더로 연결 |
| 과목 자료 | 건물 아래 강의 폴더 | 기존 `materials/연도-시즌/과목명`을 그대로 사용하고 과목 카드 더블클릭으로 열기 |
| 자료 정리 | 복사·잘라내기·붙여넣기·이름 변경·삭제·실행 취소 | 같은 동작과 단축키를 미니 자료함에 반영 |
| 선택과 탐색 | 여러 항목 선택, 빈 공간 드래그 선택, 앞·뒤 이동 | 같은 조작을 사용하며 폴더와 파일을 더블클릭해 열기 |
| 새 폴더·메모 | 새 폴더 생성, 선택 항목을 폴더에 묶기, TXT 메모 | 반영. 파일은 연결된 데스크톱 앱으로 열기 |
| 드래그앤드롭 | 건물·자료함으로 자료 넣기 | 지도 장소·과목 카드·미니 자료함에서 이동. 자료함 내부 Ctrl 드래그는 복사 |
| 파일 검색·최근 파일 | 전체 자료 검색, 최근 파일 바로 열기 | 파일 검색과 지도 옆 최근 파일 아이콘 반영 |
| 수업 변경과 자료 위치 | 건물/강의 폴더를 이동·병합해 동기화 | 기존 자료를 자동 이동하지 않고 일정 ID와 상대 경로를 연결해 이름·건물 변경 후에도 같은 폴더 사용 |
| 주간 시간표 | 요일별 시간 격자와 여러 요일 편집 | 좌우 화살표로 여는 중앙 패널의 선택 시즌 08:00~24:00 격자. 여러 요일을 한 번에 추가·수정 |
| 색상 | 파란 토요일·분홍 일요일·오늘 금색 테두리·과목별 색 | 반영. 기존 큰 글꼴과 달력 셀 대비 유지 |
| 일정·지도 기반 | 초기 반복 일정과 건물 중심 | 현재 앱의 시즌 제한·휴강/제외·할일·핀·정류장·도보 경로 유지 |

## 빠르게 사용하기

1. 지도 위 **1·2번 일정 번호를 클릭**합니다. 수업이면 그 과목 폴더, 약속·모임이면 그 장소의 일반 자료 폴더가 열립니다. 같은 건물에서 여러 일정이 진행되면 번호와 일정 이름으로 고릅니다.
2. 건물 자체를 더블클릭하면 그 장소의 과목·일반 자료 목록이 열립니다. 과목 폴더를 더블클릭하면 하위 폴더와 파일이 표시됩니다. 파일을 더블클릭하거나 Enter를 누르면 연결된 앱이 엽니다.
3. 파일 목록을 우클릭하면 복사·잘라내기·붙여넣기·이름 변경·삭제·새 폴더·새 메모 메뉴가 나옵니다. 빈 공간을 드래그해 여러 항목을 선택할 수 있습니다. 건물의 과목 목록 자체는 연결 목록이므로 과목 폴더를 먼저 연 뒤 파일을 편집합니다.
4. **파일 검색**은 자료 폴더의 파일·하위 폴더 이름을 찾습니다. 현재 과목 이름으로도 경로를 구분합니다. 최근에 연 파일이 있으면 지도 장소 옆의 파일 아이콘으로 다시 열 수 있습니다.
5. 지도 좌우 화살표로 **주간 시간표** 패널을 엽니다. 상단의 별도 주간 시간표 버튼은 없습니다. 수업 칸을 더블클릭하거나 우클릭해 편집하고 반복 요일을 여러 개 체크하면 한 수업의 요일들을 함께 저장합니다. 휴강은 이전처럼 오른쪽 하루 일정에서 그날의 해당 일정만 제외합니다.

## 파일 보존과 저장

- 미니 자료함은 실제 파일 시스템입니다. **이동·잘라내기는 원래 위치에서 파일을 옮깁니다.** 같은 이름이 있으면 `(1)`, `(2)`를 붙여 기존 파일을 덮어쓰지 않습니다.
- 삭제는 앱 전용 `.folder-trash` 보관함으로 이동합니다. `Ctrl+Z` 실행 취소 기록은 현재 실행 중에만 유지됩니다. 앱을 다시 연 뒤의 자동 실행 취소는 지원하지 않습니다.
- `data/material-folders.properties`는 일정 ID·시즌과 기존 자료 폴더의 상대 경로를 연결합니다. 수업 이름이 바뀌어도 파일이 든 폴더를 임의로 옮기거나 삭제하지 않습니다. 화면의 과목 이름은 새 이름을 사용합니다.
- `materials`의 실제 자료, 폴더 연결 정보, `.folder-recent`의 최근 열기 기록, 삭제 보관함은 일정 공유 XML에 포함되지 않습니다. 다른 기기로 자료를 옮길 때는 자료 폴더와 연결 정보도 별도로 보관해야 합니다.
- 기본 XML 버전은 3을 유지합니다. 여러 요일 수업은 안정적인 요일별 Event ID로 저장하므로 기존 일정 조회·휴강 예외·최단거리 기능을 함께 사용합니다.

이 통합을 위해 데모의 시작 프로그램·저장 위치 변경·초기 화면 전체를 덮어쓰지는 않았습니다. 필요한 기능을 기존 앱에 연결했으며, 새 기능 검사는 임시 일정과 임시 파일만 사용합니다.
