# 전남대 캠퍼스 플래너

전남대학교 광주캠퍼스의 OpenStreetMap 데이터를 사용하는 Java Swing 데스크톱 앱입니다. 주간 고정 일정에 날짜별 일정을 더하고, 선택한 하루의 장소와 이동 경로를 지도에서 확인할 수 있습니다.

## 실행

JDK 17 이상이 필요합니다. `JAVA_HOME`을 JDK 설치 폴더로 지정하거나 JDK의 `bin` 폴더를 `PATH`에 추가합니다. 외부 Java 라이브러리와 별도 빌드 도구는 필요하지 않습니다.

Windows에서 `run.cmd`를 더블클릭합니다. PowerShell에서는 다음 명령으로 실행합니다.

```powershell
.\run.ps1
```

실행 스크립트는 `src` 아래의 모든 `.java` 파일을 UTF-8, Java 17 대상으로 컴파일하고 `resources` 폴더(지도 데이터)를 함께 복사한 뒤 앱을 엽니다. JDK는 `JAVA_HOME`, `PATH`, 흔한 JDK 설치 폴더(`Program Files\Java` 등) 순서로 찾고, Oracle `javapath` 실행 도우미는 마지막 수단으로만 사용합니다. 시작 클래스는 `campus.App`입니다.

다른 OSM 파일이나 별도 개인 일정 파일로 실행하려면 경로를 지정할 수 있습니다.

```powershell
.\run.ps1 --osm "C:\maps\campus.osm" --state "C:\plans\my-planner.xml"
```

- 기본 지도: 프로그램에 포함된 `resources/map/chonnam-campus.osm` (실행 위치와 상관없이 읽습니다)
- 개인 일정 저장 파일: 프로젝트의 `data/planner-state.xml`
- 자료 파일과 자료함 메타데이터도 프로젝트의 `data` 아래에 저장합니다.
- `--osm`, `--state`의 상대 경로는 프로젝트 폴더를 기준으로 해석합니다.

## 코드 구조

```
src/campus/
 ├─ App.java       시작점 (지도·일정 불러오기, 메인 창 열기)
 ├─ model/         PlannerModel (일정·핀·즐겨찾기·할일), PlannerStore (XML 저장)
 ├─ map/           CampusMap (OSM 장소), WalkGraph (보행 그래프), RouteService (다익스트라)
 ├─ service/       DayPlanService (이동 구간), ScheduleSlot (빈 시간대)
 ├─ calendar/      CalendarPanel, Semester (학기·방학), PlannerTime, 공휴일·할일
 ├─ weather/       WeatherForecast (Open-Meteo 일별 예보)
 ├─ places/        PlaceService (사용자 핀·장소 이름·지도 연결)
 ├─ sharing/       ScheduleSharing (일정 XML 내보내기·불러오기)
 ├─ friends/       FriendSchedules, FriendsDialog, ScheduleComparison (친구 일정 저장·보기·비교)
 ├─ timetable/     TimetablePanel, TimetableService, WeekGrid, TimePicker
 ├─ materials/     CourseMaterialsPanel (학기별 과목 자료 목록)
 ├─ folder/        FolderModule, storage/ (파일·폴더 동기화·빈 폴더 정리), ui/ (미니 자료함)
 └─ ui/            MainFrame, WeekBar, PlacesPanel, MapPanel, SchedulePanel,
                   EventDialog, RouteDialog, Theme
resources/map/     전남대 OSM 지도 데이터와 출처
```

`model`, `map`, `service`에는 Swing 코드를 넣지 않습니다. 화면 패널은 `MainFrame`의 메서드를 호출해 일정을 바꾸고, 저장과 화면 갱신은 `MainFrame`이 담당합니다.

## 사용

- 중앙 화면에 마우스를 올리면 좌우 화살표가 나타납니다. **지도 → 플래너 → 주간시간표 → 달력 → 과목자료**를 순환하고, 상단 버튼으로 원하는 화면에 바로 갈 수도 있습니다.
- 달력에서 연도·월·학기/방학을 선택합니다. 반복 수업은 등록한 학기에만 표시되며 주간시간표와 과목자료도 선택 날짜의 학기를 따릅니다. 기존 학기 정보 없는 XML은 불러오는 날짜의 학기에 배정합니다.
- 주간시간표의 빈 시간대를 **위아래로 드래그**하면 시작은 30분 단위로 내림하고 종료는 5분 단위로 올려 범위를 선택한 뒤 시작·종료 시각이 채워진 일정 등록창을 엽니다. 역방향 드래그와 Esc 취소도 지원합니다. 드래그는 시작한 요일 안에서 선택합니다.
- 시간표를 세로로 스크롤해도 요일 행은 위에 고정됩니다. 일정 메모는 카드와 툴팁에서 확인할 수 있습니다. 달력의 연월 버튼을 누르면 연도 입력과 월 선택이 열립니다.
- 시간표와 우측 날짜 옆 **일정 추가**는 같은 등록창을 엽니다. 새 일정의 기본값은 **매주 반복·수업**이며, **선택한 날짜만 / 매주 반복**을 고르고 수업·동아리·조별과제·약속·특강·기타를 등록합니다. 일회성 일정은 해당 주에만, 휴강/제외는 회색으로 표시합니다. 빈칸이나 기존 일정의 **더블클릭·우클릭**으로도 추가·수정할 수 있습니다.
- 반복 일정은 여러 요일을 함께 선택할 수 있습니다. 시/분 드롭다운과 종료 시각 24:00을 지원하고 기존 요일의 휴강 정보는 유지합니다. 반복 일정을 일회성으로 바꿀 때는 기존 그룹의 모든 요일을 대체한다는 확인을 표시합니다.
- 일일 일정은 오른쪽 날짜 옆 **일정 추가** 또는 지도 장소 우클릭의 공통 등록창에서 **선택한 날짜만**을 골라 등록합니다. 일일 일정도 시·분 드롭다운과 종료 24:00을 사용하며, 기존 파일의 범위 밖·5분 단위가 아닌 시각은 수정 전까지 그대로 보존합니다. 휴강/제외는 선택한 날짜에만 적용됩니다.
- **최단거리 찾기**는 지도 영역 상단에 있습니다. 장소 우클릭으로 출발지와 도착지를 지정하면 바로 경로를 표시합니다. 검색 전의 지도 배율·위치를 유지하며 **일정 경로** 버튼으로 하루 일정 경로로 돌아갑니다.
- 지도 아래 **경로 표시** 스위치로 수업 사이 도보 경로 선을 숨기거나 다시 표시합니다. 일정 번호와 이동 거리·시간 요약은 그대로 보이며, 최단거리 찾기 결과는 스위치와 관계없이 표시합니다. 친구 지도에도 같은 설정을 적용합니다.
- 건물과 인근 버스정류장을 검색하고, 지도 빈 공간을 우클릭해 사용자 핀을 추가합니다. 장소 우클릭의 **이름 변경**으로 이름을 바꿀 수 있고, 이름 없는 건물은 목록에서 숨깁니다. 지도에서 이름 없는 건물을 선택하면 ID 없이 **이름없는 건물**로 표시합니다. 정류장도 이름만 표시하며, 핀 삭제는 우클릭 메뉴를 사용합니다. 핀 삭제 시 연결된 일정은 삭제하고 자료 파일은 보존합니다.
- 지도나 장소 목록에서 건물을 우클릭해 **메모 추가** 또는 **메모 보기·수정**을 선택합니다. 왼쪽 장소 검색에서 메모 내용으로도 건물을 찾을 수 있습니다. 건물 메모는 개인 저장 파일에 저장됩니다.
- 지도 상단 **파일 검색**을 누르면 프로그램 창 중앙에 검색어 입력창이 열립니다. 파일과 폴더 이름을 하위 폴더까지 검색하며, 폴더 결과를 더블클릭하면 해당 자료함이 열립니다.
- 지도 일정 번호를 클릭하면 해당 과목 자료함을 바로 엽니다. 같은 장소에 여러 일정이 있으면 번호·이름·시각 목록에서 고릅니다. 수업이 아닌 일정은 해당 장소 자료함으로 연결합니다. 지도 이동 드래그와 최단거리 검색의 출발·도착 표시는 이 동작을 실행하지 않습니다.
- 건물을 더블클릭하면 폴더가 없을 때 생성해서 자료함을 엽니다. 이름 없는 건물은 먼저 이름을 입력합니다. 자료함을 닫을 때 파일이 없는 건물 폴더와 빈 하위 폴더는 정리하며, 시간표 수업에 연결된 폴더는 유지합니다. 지도 빈 공간을 클릭하면 자료함이 닫힙니다.
- 빈 자료함을 정리할 때는 실제 파일·링크가 없는지 확인한 뒤 빈 디렉터리의 읽기 전용 속성을 처리합니다. 일시적인 삭제 실패는 최대 4회 재시도하고, 다시 연 자료함이나 시간표에 연결된 폴더는 보존합니다. 삭제한 파일의 실행 취소는 현재 실행 중에 지원하며, 빈 부모 폴더가 정리된 뒤에도 복구할 수 있습니다.
- 실제 과목 자료는 `data/buildings/건물명/학기/강의명`에 저장합니다. 같은 건물·강의명도 학기가 다르면 별도 폴더를 사용합니다. 수업의 건물·이름 변경 시 해당 학기 자료만 이동·병합하며, 같은 폴더를 사용하는 다른 수업이 남으면 원본을 유지합니다.
- 이전 버전의 `건물명/강의명` 자료는 처음 동기화할 때 연결된 각 학기 폴더로 복사합니다. 기존 폴더와 `data/.folder-course-backups`의 복구용 사본은 보존합니다. 같은 이름의 다른 파일은 번호를 붙여 보존합니다. 자료 백업 시 숨김 파일을 포함한 `data` 전체를 복사하세요.
- 과목자료의 과목 버튼을 더블클릭하면 선택 학기의 강의 폴더가 열립니다. 과목 카드로 외부 파일을 끌어 놓으면 해당 학기·과목 폴더로 이동합니다. 미니 자료함의 파일 이동·복사·삭제·실행 취소, 다중 선택, 새 폴더에 선택 파일 묶기는 기존과 같습니다. 외부 파일을 지도 건물 또는 자료함에 드롭하면 이동합니다.
- 하단 **일정 공유**를 누르고 **내보내기** 또는 **가져오기**를 선택합니다. 가져올 XML을 고른 뒤 **내 일정에 합치기** 또는 **친구로 가져오기**를 선택합니다. 같은 친구 이름으로 가져오면 그 친구의 기존 일정에 추가합니다. 공유 파일에는 일정·학기·휴강·일정 및 날짜 메모·즐겨찾기·핀·할일이 포함됩니다.
- **일정 공유** 옆 **친구** 아이콘으로 작은 창을 열고 이름을 누르면 해당 친구의 일정이 지도·플래너·주간시간표·달력 등에 보기 전용으로 표시됩니다. 시계 오른쪽에 적용 중인 친구 이름이 표시됩니다. **내 일정으로 돌아가기**를 누르면 과목자료를 다시 사용할 수 있습니다.
- 주간시간표 또는 달력에서 **친구와 비교하기**를 눌러 열린 창에서 친구 이름을 선택하면 왼쪽에 내 일정, 오른쪽에 그 친구의 일정이 표시됩니다. 날짜를 바꾸면 두 화면에 함께 적용됩니다. 주간시간표는 세로 스크롤도 함께 움직입니다. **마스킹으로 보기**를 누르면 두 일정을 같은 위치에 겹쳐 표시합니다. 경계선을 좌우로 드래그하거나 선택한 뒤 방향키로 움직일 수 있습니다. **분할로 보기**를 누르면 좌우에 각각 전체 일정이 표시됩니다.
- 달력 날짜를 **더블클릭**하거나 날짜 영역에서 **Enter**를 누르면 그날의 플래너로 이동합니다. 한 번 클릭은 날짜 선택이며 방향키로 하루/일주일 이동할 수 있습니다.
- 공휴일은 2025~2027년 내장 목록을 사용하며 인터넷 없이 표시됩니다.
- 상단 주간 날짜와 월간 달력에 [Open-Meteo](https://open-meteo.com/)의 광주캠퍼스 7일 예보를 날씨 아이콘과 최고·최저 기온으로 표시합니다. 앱 시작 시와 매시간 갱신하며 두 화면이 같은 응답을 사용합니다. 인터넷 연결이 필요하며 별도 API 키 설정은 필요하지 않습니다. Open-Meteo 무료 서비스는 비상업용입니다.
- 일정 종류와 장소는 목록에서 선택하거나 직접 입력합니다. 일정 간 도보 시간과 거리는 지도에서 위치를 확인할 수 있는 장소 사이에 표시됩니다.
- 탭이나 화살표로 연 **플래너**는 오늘을 표시합니다. 플래너를 보고 있을 때는 상단 날짜를 한 번 눌러 날짜를 바꿀 수 있습니다. 다른 화면에서는 상단 날짜를 더블클릭하거나 날짜에 포커스를 두고 Enter를 누르면 그날의 플래너가 열립니다.
- 체크리스트와 **과제·할일 마감**은 각각 **+ 추가**로 등록합니다. 마감은 목표·내용·마감 날짜를 입력하며, 등록한 플래너 날짜부터 마감일까지 메모 위에 표시됩니다.

## 지도와 이동 시간

지도는 OSM의 건물, 도로, 보행로와 지형 도형을 직접 그립니다. 기존에 만든 캠퍼스 PNG는 사용하지 않습니다. 이름이 등록되지 않은 건물은 화면에 **이름없는 건물**로 표시하고, 내부에서는 OSM ID로 구분하여 기존 데이터 연결을 유지합니다.

보행 그래프는 길의 굴곡 좌표를 보존하면서 차수가 2인 중간 정점을 압축하고, 다익스트라로 최단 경로를 구합니다. OSM에 출입구가 있으면 연결하고, 없으면 건물 외곽과 가까운 보행로 사이의 짧은 연결을 추정합니다. 연결을 만들 수 없는 건물은 경로를 표시할 수 없다는 안내를 보여줍니다.

예상 보행 시간은 계산한 거리를 초당 1.3m의 보행 속도로 환산합니다. 계단, 경사, 신호 대기, 실내 이동 시간은 별도로 계산하지 않습니다. OSM에 없는 강의실·층 정보나 출입구 운영 시간은 사용자 메모로 보완할 수 있습니다. 18시 일괄 폐쇄처럼 실제 데이터에 없는 통행 제한을 자동으로 적용하지 않습니다.

지도 데이터의 출처, 라이선스와 추출 범위는 `resources/map/README.md`에 기록합니다. 지도 데이터의 저작자는 OpenStreetMap 기여자이며, ODbL 라이선스가 적용됩니다.

## 저장 파일

개인 일정은 프로젝트의 `data/planner-state.xml`에 UTF-8 XML로 저장합니다. 저장할 때 같은 폴더에 임시 파일을 쓴 뒤 원래 파일을 교체합니다. 손상되었거나 지원하지 않는 버전의 파일을 읽으면 오류를 알립니다. 같은 저장 파일로 앱을 동시에 열면 덮어쓰기를 막기 위해 두 번째 실행에 안내를 표시합니다. 개인 일정 파일과 실행 잠금 파일은 `.gitignore`에서 제외합니다. 친구 일정은 `data/friends/`에 친구별 XML로 저장하며 이 폴더도 Git에서 제외합니다.

자료함 정리 실패와 재시도 결과는 `data/folder-cleanup.log`에 기록합니다. 읽기 전용 속성 및 OneDrive 환경을 고려한 처리와 검증 내용은 [빈 자료함 정리 분석](docs/folder-cleanup-analysis.md)을 참고하세요.

## Windows 배포본

`./package.ps1`을 실행하면 `dist/CNU-Schedule/CNU-Schedule.exe`와 `dist/CNU-Schedule-Windows.zip`을 만듭니다. 생성에는 jpackage가 포함된 Windows JDK 17 이상이 필요하며, 배포본에는 Java 런타임이 포함됩니다. ZIP을 모두 풀고 실행 파일·app·runtime 폴더를 함께 보관하세요. 사용자 일정과 실제 자료 파일은 배포 ZIP에 넣지 않습니다. 실행 파일 옆 data 폴더에 개인 데이터를 저장하므로 쓰기 가능한 위치에 압축을 풉니다.

## 작업 공간과 원본 자료

- 상단 **중앙 확대 / 원래 크기**로 좌우 패널과 주간 날짜를 숨기거나 복원합니다. 화면 전환 후에도 확대 상태를 유지합니다.
- 지도에는 폴더가 있는 건물의 자료함 아이콘을 표시합니다. 최근 파일이 있으면 최근 파일 아이콘을 우선합니다.
- 과목자료의 **원본 디렉터리 열기**, 미니 자료함 우클릭의 **원본 폴더 열기**로 실제 폴더를 탐색기에서 엽니다.
- 과목 카드·원본 디렉터리 버튼에 파일을 드롭하면 해당 학기 과목 폴더로 이동하며, 중복 이름은 덮어쓰지 않습니다.

## 시계·타이머·마감 알림

- 상단 디지털 시계는 한국 시각을 표시합니다. 옆의 시계 아이콘을 누르면 시계·타이머·스톱워치 창이 열립니다. 아날로그 시계 바깥 색 띠는 선택 날짜의 오전 또는 오후 일정을 표시합니다. 띠에 마우스를 올리면 일정 이름과 시간이 표시됩니다.
- 스톱워치는 시작·일시정지·계속·초기화를 지원합니다. 타이머와 스톱워치는 창을 닫아도 앱을 실행하는 동안 계속 동작합니다.
- 분 단위 타이머는 1분~24시간을 설정하고 시작·일시정지·계속·초기화할 수 있습니다. 화면을 전환해도 계속 동작하며 앱 종료 시 해제합니다.
- 미완료 할일 중 **내일 마감·오늘 마감** 항목을 앱 시작, 데이터 갱신 및 1분 간격으로 확인합니다. 같은 항목·마감일은 하루 한 번 알리며, 기록을 로컬에 보관해 재시작 후 중복을 줄입니다.
- 타이머가 끝나거나 할일 마감이 다가오면 Windows 작업 표시줄 알림 영역과 앱 하단에 알림을 보냅니다. **앱이 실행 중일 때만** 동작하며, Windows의 알림 설정과 방해 금지 상태에 따라 바탕화면 알림의 표시 여부가 달라질 수 있습니다.
- 완료·삭제된 할일은 알리지 않으며 마감일을 변경하면 새 기준으로 판단합니다. 알림 기록 저장 실패 시 현재 실행의 중복은 막고 상태 툴팁으로 안내합니다.
