# 전남대학교 일정

전남대학교 광주캠퍼스 OpenStreetMap 데이터를 사용하는 Java Swing 일정 앱입니다. 반복 수업과 일일 일정·할일을 함께 관리하고, 건물·버스정류장·핀 사이의 도보 경로를 확인합니다.

## Windows에서 실행

배포 ZIP을 **모두 압축 해제**하고 `CNU-Schedule` 폴더의 `CNU-Schedule.exe`를 실행합니다. Java를 따로 설치할 필요가 없습니다. 실행 파일과 `app`, `runtime` 폴더를 함께 보관하고, 쓰기 가능한 위치에 압축을 풉니다. 자세한 방법은 [Windows 실행본 안내](docs/windows-package.md)에 있습니다.

개발 소스로 실행하려면 JDK 17 이상이 필요합니다. `JAVA_HOME` 또는 `PATH`에 실제 JDK를 지정한 후 `run.cmd`를 더블클릭합니다. PowerShell 실행 정책으로 스크립트가 차단되는 경우 프로젝트 폴더에서 다음 명령을 사용합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
```

별도 지도나 저장 파일도 지정할 수 있습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 --osm "C:\maps\campus.osm" --state "C:\plans\my-planner.xml"
```

외부 Java 라이브러리나 별도의 빌드 도구는 필요하지 않습니다. 실행 스크립트는 Java 17 대상으로 UTF-8 컴파일하며 Oracle `javapath` 도우미를 건너뛰고 실제 JDK를 찾습니다.

## 장소와 경로

- 왼쪽에는 이름 있는 건물, OSM에 등록된 인근 버스정류장, 사용자 핀을 표시합니다. 같은 이름의 정류장은 위치를 구분해 표시합니다. 이름 없는 건물도 지도에서 선택할 수 있으며 더블클릭해 이름을 지으면 목록에 나타납니다.
- 이름 있는 장소를 더블클릭하면 해당 시즌의 과목·일반 자료를 보여주는 미니 자료함이 열립니다. 지도 **1·2번 일정 번호는 해당 과목 폴더로 직접 연결**되며, 같은 건물의 여러 일정은 번호·이름으로 고릅니다. 즐겨찾기와 이름 변경도 지원합니다.
- 장소를 우클릭하면 자료함 열기·일정 추가·여기서 출발·여기로 도착 메뉴를 사용합니다. 빈 지도에서 우클릭하면 이름을 정해 핀을 추가합니다. 핀도 일정 장소와 최단거리 검색에 사용할 수 있습니다.
- 핀을 선택하면 왼쪽에 **핀 삭제** 버튼이 나타납니다. 삭제 전 연결된 일정도 함께 삭제된다는 안내를 표시합니다.
- 지도 패널의 **최단거리 찾기**에서 출발·도착 장소를 선택합니다. 장소 목록이 잘리지 않도록 검색 팝업을 넓혔습니다. **일정 경로**를 누르면 그날 일정의 이동 경로로 돌아갑니다.
- 지도는 마우스 휠로 확대하고 드래그로 이동합니다. 정류장까지의 경로도 도보 경로이며 버스 노선·실시간 도착 정보는 제공하지 않습니다.

## 일정과 시즌

- 오른쪽 하루 일정의 맨 위·맨 아래 **+ 일정 추가**, 장소 우클릭의 **일정 추가**, 시간표의 빈칸으로 등록합니다. 일정 사이의 추가 버튼과 전역 파란 일일 일정 추가 버튼은 제거했습니다.
- 맨 위의 +는 첫 일정 시작 시각에 종료 시각을 맞추고, 맨 아래의 +는 마지막 일정 종료 시각에 시작 시각을 맞춥니다. 일정이 없으면 기본 시각을 제안합니다.
- **시와 분을 따로 선택**합니다. 시는 08~24, 분은 00·05·10…55이며 24시는 종료 시각의 24:00으로만 사용합니다. 이전 파일의 다른 단위·범위 시각은 편집 시 그대로 보존합니다.
- 과거 날짜에서 **새 일정·할일을 추가하면 오늘 날짜**를 사용하고, 미래 날짜를 선택했다면 그 날짜를 사용합니다. 날짜와 지난 시각의 기준은 **한국 시간(Asia/Seoul)**입니다. 기존 일정·할일을 편집할 때는 원래 날짜와 시각을 유지합니다.
- 시간이 겹치면 중복을 알리고 계속 저장할지 묻습니다. 휴강·제외된 날짜도 충돌 계산에 반영합니다.
- 좌우 화살표로 여는 **주간 시간표**는 선택 시즌의 월~일, 08:00~24:00 반복 일정을 표시합니다. 수업을 더블클릭하거나 우클릭해 편집하고, 반복 요일을 여러 개 체크해 한 번에 등록·수정합니다. 남아 있는 요일의 휴강 예외는 유지합니다.
- 반복 일정의 **휴강**, 일일 일정의 **제외**는 그날만 적용하며 **복원**할 수 있습니다. 제외한 일일 일정에는 왼쪽에 빨간 **삭제** 버튼이 나타납니다. 삭제하면 해당 일정 자체가 제거됩니다.
- 일정 사이에는 유효한 일정의 도보 거리와 예상 시간만 표시합니다. 제외된 일정은 경로 계산에서 빠집니다.
- 날짜별 메모와 일정별 메모는 자동 저장합니다. 종료 시각이 지난 일정은 회색으로 표시합니다. **미완료 할일은 마감이 지나도 빨간색을 유지**합니다.

시즌은 **26-1학기 · 26-여름방학 · 26-2학기 · 26-겨울방학**처럼 구분합니다.

- **1학기**: 3월 2일 당일 또는 이후의 첫 평일부터 16주입니다.
- **여름방학**: 1학기 종료 다음 날부터 2학기 시작 전날까지입니다.
- **2학기**: 9월 1일 당일 또는 이후의 첫 평일부터 16주입니다.
- **겨울방학**: 2학기 종료 다음 날부터 다음 해 1학기 시작 전날까지입니다. 예를 들어 2027년 1월은 **26-겨울방학**에 속합니다.

추가 창의 **매주 반복**을 선택하면 해당 시즌의 고정 일정이 됩니다. **반복 일정은 배정된 시즌에만 표시**되므로 방학에 넣은 일정이 학기 중에 반복되지 않습니다. 공휴일이더라도 시즌 시작일이나 수업을 자동으로 옮기지 않습니다. 일일 일정은 지정한 날짜에 표시합니다. 이전 버전 XML의 시즌 없는 반복 일정은 읽는 날의 시즌으로 배정합니다.

## 패널 전환과 할일

지도 좌우의 반투명 화살표로 **지도 → 달력 → 주간 시간표 → 과목 자료**를 순환합니다. 주간 시간표는 중앙 패널에서 표시하며 별도의 상단 버튼은 없습니다. 오른쪽 하루 일정과 메모는 선택한 날짜를 계속 표시합니다. 전반적인 글꼴 크기는 이전보다 3px 키웠습니다.

- **달력**: 일·월·화·수·목·금·토 순서이며, 일요일과 공휴일은 빨간색, 토요일은 파란색입니다. 셀 경계와 선택 배경의 대비를 높였습니다. 1일이 포함된 주부터 **기본 5주**, 모든 날짜를 담는 데 필요한 달만 **6주**를 표시합니다.
- 왼쪽의 **연도·월 선택**과 오른쪽 **오늘**로 이동합니다. 별도 시즌 목록에서 해당 시즌 시작일로 이동할 수도 있습니다. 날짜 칸을 선택한 뒤 방향키를 누르면 좌우는 하루, 위아래는 한 주씩 바로 옆 칸으로 이동합니다. 월 경계를 넘으면 달력도 이전·다음 달로 바뀝니다.
- 날짜의 개수는 취소되지 않은 **수업·동아리·약속 등 모든 일정과 할일의 합계**입니다. 공휴일은 개수에 넣지 않습니다. 날짜 칸은 휴일·휴강·제외를 우선해 최대 두 줄로 표시하며 나머지 할일은 요약과 마우스 툴팁으로 확인합니다. 날짜를 누르면 오른쪽에 전체 목록이 나타납니다.
- **+ 할일 추가**에서 이름·날짜·메모를 적고 **완료** 체크박스로 상태를 바꿉니다. 과제 이외의 할일도 등록할 수 있습니다.
- **하루 일정**: 할일도 함께 표시합니다. 미완료는 빨간 마감일·미완료, 완료는 회색 완료 날짜·완료로 표시합니다. 제출이라는 표현을 사용하지 않습니다.
- **주간 시간표**: 선택한 시즌의 반복 일정을 월~일, 08:00~24:00 격자로 표시합니다. 빈칸을 더블클릭하거나 우클릭하면 해당 요일·시각으로 수업 추가 창이 열립니다. 일일 약속과 휴강 등 날짜별 상태는 오른쪽 하루 일정에서 확인합니다.
- **과목 자료**: 선택한 시즌의 반복 수업을 과목별 네모 버튼으로 표시합니다. **더블클릭**하면 `materials/2026-2학기/과목명` 같은 실제 폴더의 미니 자료함을 엽니다. 기존 `2026-봄`·`2026-가을` 폴더도 계속 사용하고, 수업 이름·건물이 바뀌어도 저장된 자료 위치를 유지합니다.
- 자료를 **지도 장소·과목 버튼·미니 자료함으로 끌어 놓으면 이동**합니다. 원래 위치에서는 사라지며 같은 이름이 있으면 번호를 붙여 기존 파일을 보존합니다. 자료함 내부에서는 Ctrl 드래그로 복사할 수 있습니다. 심볼릭 링크는 지원하지 않습니다.
- 미니 자료함에서 폴더·파일을 더블클릭해 열고, 우클릭이나 `Ctrl+C/X/V`, `F2`, `Delete`, `Ctrl+Z`로 정리합니다. 빈 공간 드래그로 여러 항목을 선택하고 새 폴더·TXT 메모도 만들 수 있습니다. 삭제는 앱 전용 보관함으로 이동하며 실행 취소는 현재 실행 중에 지원합니다.
- 지도 패널의 **파일 검색**에서 자료를 찾습니다. 최근에 연 파일은 지도 장소 옆 파일 아이콘으로 다시 열 수 있습니다. 상단 주간 날짜에는 일정 개수, 토요일은 하늘색·일요일은 분홍색, 오늘은 금색 테두리로 표시합니다.

공휴일은 공식 자료로 확인한 **2025~2027년 날짜를 오프라인으로 표시**합니다. 실시간 조회가 아니며 확인 범위 밖의 연도에는 자료가 없다는 안내를 표시합니다. 향후 임시공휴일 지정이나 법령 변경은 데이터 갱신이 필요합니다. 출처는 [data/README.md](data/README.md)에 있습니다.

제외한 일정의 회색 배경·**복원** 버튼과, 유효한 일정의 **휴강/제외** 버튼은 서로 다른 상태를 나타냅니다. 지난 일정도 회색으로 표시하지만, 휴강·제외를 누르지 않았다면 일정과 도보 경로에는 남습니다.

## 저장과 공유

소스 실행 시 지도는 `data/chonnam-campus.osm`, 사용자 정보는 `data/planner-state.xml`에 있습니다. Windows 배포본에서는 실행 파일 옆 `data/planner-state.xml`과 `materials`를 사용하며, 지도 원본은 `app/data`에 있습니다.

**공유하기**로 XML 파일을 저장해 전달하고, 상대방은 **가져오기**로 합칩니다. 시즌, 일정, 휴강·제외 예외, 할일, 완료 날짜, 사용자 장소 이름, 핀, 즐겨찾기와 메모가 포함됩니다. 동일 파일을 다시 가져올 때 중복을 줄이고 기존 데이터를 임의로 덮어쓰지 않습니다. **과목 폴더 안의 실제 파일과 OSM 지도는 공유 XML에 포함되지 않습니다.**

과목 폴더의 로컬 연결은 `data/material-folders.properties`, 최근 파일은 `.folder-recent`, 삭제 보관함은 `.folder-trash`에 저장합니다. 이 파일 정보도 공유 XML에는 포함하지 않습니다. 여러 요일 수업은 기존 XML 안의 요일별 일정으로 저장합니다.

XML은 임시 파일을 쓴 뒤 교체하며 같은 저장 파일로 동시 실행하는 것을 막습니다. 이전 버전 XML도 읽습니다. 기존 `spring`·`fall` ID를 유지하면서 `summer`·`winter`를 추가해 XML 버전 3으로 저장합니다. 방학 시즌을 읽으려면 최신 앱을 사용해야 합니다. 배포 ZIP에는 개인 일정과 자료 파일을 넣지 않습니다.

## 지도 정확도

OSM 건물·도로·보행로·정류장 좌표를 직접 읽습니다. 굴곡 좌표를 보존하며 차수가 2인 정점을 압축한 보행 그래프를 사용합니다. 정점이 900개 이하면 플로이드–워셜, 더 크면 다익스트라를 적용하며 현재 전남대 데이터는 압축 후 2,395개 정점이므로 다익스트라를 사용합니다.

등록된 출입구가 없으면 건물과 가까운 보행로 사이의 짧은 연결을 추정합니다. 핀과 정류장도 가까운 보행로에 연결하며 연결할 수 없으면 경로 없음을 표시합니다. 거리에서 **1.3m/s**로 보행 시간을 환산합니다. 경사, 신호 대기, 실내 이동, 출입문 운영 시간은 별도로 반영하지 않습니다.

지도 출처와 추출 범위는 [data/README.md](data/README.md)에 있습니다. © OpenStreetMap contributors, ODbL.

## 개발과 검증

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\check.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\package.ps1
```

`check.ps1`은 별도 임시 상태로 모델·XML·시즌·중복 시간·시/분 입력·날짜 기본값·달력·파일 이동·실제 OSM 경로·Swing 화면 연결을 검사합니다. 사용자 저장 파일을 수정하지 않습니다. `package.ps1`은 Java 런타임을 포함하는 Windows 앱 폴더와 ZIP을 `dist`에 만듭니다. 기존 출력이 있으면 날짜가 붙은 별도 경로를 사용합니다.

영재 데모와의 차이·새 자료함 사용법은 [데모 통합 문서](docs/demo-merge.md), 역할별 클래스 설명과 Mermaid 클래스 다이어그램은 [설계 문서](docs/design.md), 아직 구현하지 않은 추가 제안은 [아이디어](docs/ideas.md)에 정리했습니다.
